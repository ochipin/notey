## 仕組み

Notey は検索の画面と、検索に使う [MiniSearch](https://github.com/lucaong/minisearch) 7.2.0 をテーマに同梱しています。検索インデックスは Hugo のビルド時に言語ごとの JSON として生成され、最初に検索ダイアログを開いたときにブラウザが読み込みます。外部サービスへの通信はありません。

日本語のように単語の区切りがない文章は 2 文字ずつに分けて索引を作るため、語の途中からでも検索できます。

## ビルド手順

```bash
hugo --minify
```

{{< info title="追加の手順は不要" >}}
ビルドのあとに別のコマンドを実行する必要はありません。`hugo server` のプレビューでも検索できます。
{{< /info >}}

## 検索対象

記事の本文（タイトル・見出し・本文）が対象です。検索結果には、一致した記事の総件数と、一致した見出しを記事ごとに最大 3 件表示します。

## ショートカット

| キー | 動作 |
|:--|:--|
| Ctrl / ⌘ + K | 検索を開く |
| / | 検索を開く |
| ↑ ↓ | 候補を移動 |
| Enter | 開く |
| Esc | 閉じる |
