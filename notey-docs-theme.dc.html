はじめる

Notey を Hugo サイトに導入し、最初のページを公開するまでの手順。

2026-09-12 · 4日前 約 4 分 このページを編集

Hugo v0.166.0 以上（extended 不要）と Git があれば動きます。検索インデックスの生成にだけ Node.js を使います。

インストール

Hugo Modules

Hugo Modules で導入する場合は、サイトをモジュールとして初期化してから hugo.yaml に 1 行足すだけです。

bash terminal 
# サイトを作ってモジュール化する
hugo new site mydocs && cd mydocs
git init && hugo mod init github.com/you/mydocs
hugo mod tidy

themes/ 直置き

サブモジュールとして themes/notey に置き、theme: notey を指定しても同じように動きます。

ノート

enableGitInfo: true を設定すると、記事の更新日時を Git のコミットから自動で表示します。

環境ごとの手順

{{ tabCode }}

大きな画像の扱い

本文の画像は段幅に合わせて自動で縮小し、WebP の srcset を付けて配信します。横スクロールは発生せず、クリックで原寸をライトボックス表示します。

幅の指定

![](img.png#inline) で小さめ、#wide で段幅より広く表示します。

公開までの流れ

  1. 1 本文を書く。画像はページと同じディレクトリに置きます。
  2. 2 ビルドして検索インデックスを生成する。 
    hugo --minify
npx -y pagefind --site public
  3. 3 public/ を配信する。

注意

Pagefind を実行しないと検索ダイアログにインデックス未生成のメッセージが出ます。他の機能は通常どおり動きます。

キー 動作
Ctrl / ⌘ + K検索を開く
/検索を開く
↑ ↓ / Enter候補を移動して開く
