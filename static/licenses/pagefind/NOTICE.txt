Notey provides the search interface. The site builder runs Pagefind to
generate the search JavaScript, WebAssembly, and index files separately.
The reference version used by the Notey review site is Pagefind 1.5.2.
This directory contains license notices, not a copy of the Pagefind CLI.

Additional browser runtime copyright and license notices are preserved in
dependencies/. Its SOURCES.json identifies their versions, source locations,
and checksums. Each component keeps its own license.

DISTRIBUTION

Keep this directory with the generated site's Pagefind assets when publishing
or redistributing the site. Hugo publishes these files under licenses/pagefind/,
separately from the generated pagefind/ directory, so regenerating the search
index does not replace them.

If you change the Pagefind version used to build your site, review that release's
licenses and dependency notices and update these copies to match. Applications
that also distribute the Pagefind CLI or npm runner must preserve the notices
for those additional components; they are outside this theme's browser assets.
